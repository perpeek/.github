**perpeek**, yapay zekâ asistanları için bir eklenti pazaryeridir. Kullanıcının asistanı, kurumlardan gelen güncel ve doğrulanmış veriye eklentiler üzerinden bakarak cevap verir. Eklentiler ChatGPT, Claude ve diğer MCP istemcilerine bağlanır; yanında Windows uygulaması, Türkçe modeller ve yetenekler bulunur.

### Geliştiriciler için

perpeek eklentileri [Model Context Protocol (MCP)](https://modelcontextprotocol.io) sunucularıdır. Kendi MCP sunucunu tek uç ve tek anahtar arkasında yayınlayabilir, abonelik ve ödemeyi perpeek'e bırakabilirsin. Komut satırı aracı ve SDK yakında burada açık kaynak olarak yayınlanacak.

- Belgeler: https://perpeek.com/docs
- Eklentini yayınlamak için: merhaba@perpeek.com
